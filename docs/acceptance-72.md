# Keyboard contract acceptance evidence

The final map is [keymap.md](keymap.md), corresponding to #72's 21-section normative appendix. Automated acceptance uses RecordingTerminal → DeckTui → ApplicationController/store → FakePaseoGateway, with clipboard/link effects substituted only at the external boundary. Production gateway tests separately exercise installed SDK/CLI contracts. Pure buffer tests supplement detailed aliases, Unicode and boundary cases; they do not establish physical input delivery.

This is partial acceptance. Physical keyboard delivery and cross-application clipboard round trips remain unverified. Computer Use access to Ghostty was explicitly denied; TextEdit inspection returned `cgWindowNotFound`. No alternate automation bypass was attempted. Synthetic escape sequences and headless cells cannot establish those host capabilities.

## Captures and live evidence

`scripts/capture-ui-report.ts <directory>` writes SVGs, exact terminal cells/backgrounds, emitted cursor positions and a manifest. Input-driven shots now execute application/store effects instead of discarding mode intents, and advance deterministic queued repaint frames. `capture-report.test.ts` checks actual generated Composer/Timeline Visual cells. The audit also fixed a production Composer repaint omission: consumed cursor/selection motions now request a frame even when no store event occurs; `final-acceptance.test.ts` waits for each individual key and checks selection feedback. Final review regressions also exercise legacy, CSI-u and modifyOtherKeys globals, Normal actions, paging, redo and picker navigation; pending Composer/Timeline commands are consumed before one half-page scroll. Deck owns framed input before inherited fullscreen handlers, suppressing removed Sidebar/page/prompt/search aliases while retaining direct Terminal bytes. These are synthetic input checks. Static fixtures are explicitly labelled. Every shot records its source revision, dirty-tree flag, dimensions, injected appearance, input sequence, requirement, baseline path or missing-before reason and limitations. SVG cursor rectangles demonstrate position only. RecordingTerminal records cells/backgrounds, not foreground colors; the SVG renderer uses fixed root/text colors. Injected light-background shots therefore establish layout and backgrounds only, not actual terminal foreground or light-theme contrast.

The external final capture inventory is `/tmp/paseo-spec-72/captures93/manifest.json`; the pinned baseline is revision `6591925` under `/tmp/paseo-spec-72/before-png`. Legacy Ctrl-K palette, Visual Block, Terminal mode and Session-wizard fixture meanings have been replaced. New captures include wrapped character/line Visual at 100/64/52 columns, offscreen/background/refocused Timeline selection, search/settings, both Workspace placements/resource kinds, Sidebar combined filters, pickers, confirmations, diagnostics and direct Terminal input. Final PNG inspection and the persistent single-file HTML report are recorded by the integration owner; source generation alone is not visual approval. Baseline fixtures did not contain every new state; those missing comparisons are explicit in the manifest.

The isolated native 0.8.0 resource probe recorded actual Worktree creation from advertised origin default with matching Git commit, two distinct Local Workspace IDs at the same checkout, profile Terminal cwd, Terminal rename/readback preserving name/ID/cwd/shell PID, and Workspace rename/archive. This verifies those resource operations, not physical keyboard delivery. The corrected native probe also passed for both Worktree and Local Sessions using Codex `gpt-6.1-sol`: empty creation sent no prompt; exactly one submitted prompt returned merged `DECK72_OK`; rename and same-model update read back; thinking changed high → low; operational mode changed auto-review → auto; refocus preserved identity and exactly one user message. The original probe had overwritten assistant delta fragments instead of using the existing store merge; no production defect was established. Probe-owned Sessions/Workspaces were archived, owned daemons stopped and ports 17679/17680 verified clear. Exact native evidence remains outside the repository in `/tmp/paseo-spec-72/live-resource-actions.json`, `live-timeline-sessions.json` and `result-live-timeline.md`.
